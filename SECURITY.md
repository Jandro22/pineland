# Security and sensitive-material reporting

Pineland is research software. Please do not open a public issue containing
credentials, private data, restricted research material, or details that would
make an accidental disclosure worse.

For a suspected security vulnerability or sensitive-material disclosure, use
GitHub's private vulnerability-reporting or Security Advisory mechanism when it
is available for the repository. If that mechanism is unavailable, contact the
maintainer privately through the GitHub account associated with this repository
before publishing details.

Reports are especially useful for:

- exposed credentials or tokens;
- unsafe handling of untrusted files or configuration;
- accidental inclusion of private or restricted datasets;
- dependency or build-chain vulnerabilities;
- reproducibility controls whose failure could silently change scientific results.

Scientific disagreements, model-validity concerns, and ordinary bugs do not
need confidential handling unless they also expose sensitive information.
