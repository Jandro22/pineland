# Native validation archive

This directory retains historical Python/Rust parity and trajectory-validation
evidence. Files under `legacy_2026_09/` were formerly loose in the repository
root; they were moved here without changing their contents so their diagnostic
history is preserved while the root remains reserved for project entry points.

These certificates include both successful and failed intermediate checks. A
failed certificate is evidence about the development history, not disposable
junk, and should not be silently rewritten as a passing result.
